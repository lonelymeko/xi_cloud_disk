# 存储服务配置使用指南

## 快速开始

### 1. 复制配置模板

```bash
cp .env.example .env
```

### 2. 选择存储服务

编辑 `.env` 文件，修改 `STORAGE_TYPE` 参数：

```bash
# 使用阿里云 OSS
STORAGE_TYPE=oss

# 或使用火山云 TOS
STORAGE_TYPE=tos
```

## 配置详解

### OSS 配置（阿里云对象存储服务）

```bash
STORAGE_TYPE=oss
OSS_ACCESS_KEY_ID=your_access_key
OSS_ACCESS_KEY_SECRET=your_secret_key
OSS_REGION=cn-beijing
OSS_BUCKET_NAME=your-oss-bucket
```

**获取 OSS 凭证步骤：**
1. 登录阿里云控制台 https://console.aliyun.com/
2. 进入 RAM 访问控制，创建或使用现有的 Access Key
3. 复制 AccessKeyID 和 AccessKeySecret
4. 通过 OSS 控制台创建 Bucket，记录 Bucket 名称和回源区域

**OSS 区域代码：**
- 华北2（北京）: `cn-beijing`
- 华东1（杭州）: `cn-hangzhou`
- 华南1（深圳）: `cn-shenzhen`
- 更多区域见：https://help.aliyun.com/document_detail/31837.html

### TOS 配置（火山云对象存储服务）

```bash
STORAGE_TYPE=tos
VOLCENGINE_ACCESS_KEY_ID=your_access_key
VOLCENGINE_SECRET_ACCESS_KEY=your_secret_key
VOLCENGINE_REGION=cn-beijing
VOLCENGINE_ENDPOINT=tos-cn-beijing.volces.com
VOLCENGINE_BUCKET_NAME=your-tos-bucket
```

**获取 TOS 凭证步骤：**
1. 登录火山引擎控制台 https://console.volcengine.com/
2. 进入 IAM，创建或使用现有的 Access Key
3. 复制 Access Key ID 和 Secret Access Key
4. 通过对象存储（TOS）服务创建 Bucket
5. 从 Bucket 信息中获取 Endpoint 和区域信息

**TOS 区域和端点对应关系：**
- 华北-北京: `tos-cn-beijing.volces.com` (region: `cn-beijing`)
- 华东-上海: `tos-cn-shanghai.volces.com` (region: `cn-shanghai`)
- 更多端点见火山云文档

## 运行时动态切换

应用启动时会自动读取 `STORAGE_TYPE` 环境变量并初始化对应的存储服务。

### 代码中初始化存储

```go
import "cloud_disk/core/utils"

// 从环境变量自动创建存储实例
err := utils.InitStorage(utils.StorageConfig{
    Type:    os.Getenv("STORAGE_TYPE"),
    Region:  os.Getenv("STORAGE_REGION"),
    // ... 其他配置
})

// 获取存储实例使用
storage, err := utils.GetStorage()
```

### 程序化切换存储

```go
// 从 OSS 切换到 TOS
err := utils.InitStorage(utils.StorageConfig{
    Type:            "tos",
    Region:          "cn-beijing",
    Endpoint:        "tos-cn-beijing.volces.com",
    BucketName:      "my-bucket",
    AccessKeyID:     "your_key",
    AccessKeySecret: "your_secret",
})

// 使用新存储实例
storage, _ := utils.GetStorage()
```

## 常见问题

### Q: 可以同时使用 OSS 和 TOS 吗？

**A:** 当前实现支持全局单一存储，但可以：
1. 在启动时根据环境变量选择一个存储
2. 或修改代码支持多存储并发管理（需要额外开发）
3. 通过反复调用 `InitStorage()` 实现运行时切换

### Q: 如何验证存储连接？

**A:** 运行连通性测试：
```bash
# OSS
go test -v ./test -run TestOSSConnectivity

# TOS
go test -v ./test -run TestTOSStorageManager
```

### Q: 测试文件上传速度太慢？

**A:** 
- 检查网络连接和带宽
- TOS 分片上传默认每片 5MB，可根据网络调整
- 减少日志输出级别：`LOG_LEVEL=warn`

### Q: 如何迁移现有数据？

**A:** 从 OSS 迁移到 TOS（反之亦然）：
1. 使用两个存储实例分别读写
2. 通过流式处理避免内存溢出：
   ```go
   reader, _ := ossStorage.GetObject(ctx, key)
   _ = tosStorage.PutObject(ctx, key, reader, size, contentType)
   ```

## 环境变量汇总

| 变量 | 必需 | 说明 |
|------|------|------|
| `STORAGE_TYPE` | ✓ | 存储类型: `oss` 或 `tos` |
| `OSS_ACCESS_KEY_ID` | 仅OSS | 阿里云 AccessKey ID |
| `OSS_ACCESS_KEY_SECRET` | 仅OSS | 阿里云 AccessKey Secret |
| `OSS_REGION` | 仅OSS | OSS 区域代码 |
| `OSS_BUCKET_NAME` | 仅OSS | OSS 存储桶名称 |
| `VOLCENGINE_ACCESS_KEY_ID` | 仅TOS | 火山云 AccessKey ID |
| `VOLCENGINE_SECRET_ACCESS_KEY` | 仅TOS | 火山云 Secret Access Key |
| `VOLCENGINE_REGION` | 仅TOS | TOS 区域代码 |
| `VOLCENGINE_ENDPOINT` | 仅TOS | TOS 服务端点 |
| `VOLCENGINE_BUCKET_NAME` | 仅TOS | TOS 存储桶名称 |

## 故障排查

### 启动错误：`failed to initialize storage`

检查：
1. `STORAGE_TYPE` 是否正确（`oss` 或 `tos`）
2. 对应的凭证环境变量是否设置
3. 凭证是否正确有效

### 上传失败：`access denied`

检查：
1. AccessKey ID 和 Secret 是否正确
2. 存储桶是否存在
3. IAM 权限是否包含存储操作权限

### 网络超时

检查：
1. 网络连接是否正常
2. 防火墙是否阻止了请求
3. 增加超时时间进行测试
