## 快速使用

### 步骤 1：配置环境

```bash
# 复制配置模板
cp .env.example .env

# 编辑 .env，选择存储类型
STORAGE_TYPE=oss  # 或 tos
```

### 步骤 2：配置对应的凭证

**使用 OSS：**
```bash
STORAGE_TYPE=oss
OSS_ACCESS_KEY_ID=your_key
OSS_ACCESS_KEY_SECRET=your_secret
OSS_REGION=cn-beijing
OSS_BUCKET_NAME=your-bucket
```

**或使用 TOS：**
```bash
STORAGE_TYPE=tos
VOLCENGINE_ACCESS_KEY_ID=your_key
VOLCENGINE_SECRET_ACCESS_KEY=your_secret
VOLCENGINE_REGION=cn-beijing
VOLCENGINE_ENDPOINT=tos-cn-beijing.volces.com
VOLCENGINE_BUCKET_NAME=your-bucket
```

### 步骤 3：启动应用

```bash
cd core
go run core.go -f etc/core-api.yaml
```

应用会自动按照 `STORAGE_TYPE` 初始化存储系统。

### 步骤 4：运行测试

```bash
# 测试 TOS 功能
go test -v ./test -run TestTOS

# 测试 OSS 功能（原有）
go test -v ./test -run TestUploadToOSS
```

## 代码使用示例

### 初始化存储（自动）

应用启动时 `core.go` 会自动调用：
```go
config.InitializeStorage()  // 从环境变量初始化
```

### 获取和使用存储

```go
import "cloud_disk/core/utils"

// 获取存储实例
storage, err := utils.GetStorage()
if err != nil {
    panic(err)
}

// 上传文件
err = storage.PutObject(ctx, "path/to/file", reader, size, "application/octet-stream")

// 生成分享链接
url, err := storage.GetPresignedURL(ctx, "path/to/file", 1*time.Hour)

// 删除文件
err = storage.DeleteObject(ctx, "path/to/file")
```

### 分片上传

```go
// 初始化
uploadID, err := storage.InitiateMultipartUpload(ctx, key, contentType)

// 并发上传分片
parts := []utils.Part{}
for i := 1; i <= numParts; i++ {
    etag, err := storage.UploadPart(ctx, key, uploadID, i, partReader, partSize)
    parts = append(parts, utils.Part{PartNumber: i, ETag: etag})
}

// 完成
err = storage.CompleteMultipartUpload(ctx, key, uploadID, parts)
```

## 架构特点

### 🎯 接口统一
Both OSS and TOS implement the same `ObjectStorage` interface, enabling seamless switching:

```
用户代码 → ObjectStorage 接口 → OSS/TOS 实现
```

### 🔄 动态切换
支持运行时切换存储服务：
```go
// 从 OSS 切换到 TOS
utils.InitStorage(utils.StorageConfig{Type: "tos", ...})
storage, _ := utils.GetStorage()  // 获取新实例
```

### 🔒 单例管理
全局存储管理器确保：
- 单一存储实例
- 线程安全
- 生命周期管理

### 📦 完整兼容性
- 支持分片上传
- 支持预签名 URL
- 支持错误处理
- 支持上下文超时

## 迁移现有代码

### 原有方式（仍可用）
```go
key, err := utils.UploadToOSS(reader, filename)
url, err := utils.PresignGetObject(ctx, key, expires)
err := utils.DeleteOSSObject(ctx, key)
```

### 新方式（推荐）
```go
storage, _ := utils.GetStorage()
err := storage.PutObject(ctx, key, reader, size, contentType)
url, _ := storage.GetPresignedURL(ctx, key, expires)
err := storage.DeleteObject(ctx, key)
```
