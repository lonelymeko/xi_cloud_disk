# 对象存储统一接口集成指南

## 概述

本项目现已集成了统一的对象存储接口，支持以下存储提供商：
- **阿里云 OSS** (Alibaba Cloud Object Storage Service)
- **火山云 TOS** (Volcengine Object Storage)

## 架构设计

### 核心接口

```go
type ObjectStorage interface {
    // 上传单个对象
    PutObject(ctx context.Context, key string, body io.Reader, size int64, contentType string) error

    // 下载对象
    GetObject(ctx context.Context, key string) (io.ReadCloser, error)

    // 删除单个对象
    DeleteObject(ctx context.Context, key string) error

    // 初始化分片上传
    InitiateMultipartUpload(ctx context.Context, key string, contentType string) (uploadID string, err error)

    // 上传单个分片
    UploadPart(ctx context.Context, key string, uploadID string, partNumber int, body io.Reader, size int64) (etag string, err error)

    // 完成分片上传
    CompleteMultipartUpload(ctx context.Context, key string, uploadID string, parts []Part) error

    // 取消分片上传
    AbortMultipartUpload(ctx context.Context, key string, uploadID string) error

    // 生成预签名 URL（用于下载和分享）
    GetPresignedURL(ctx context.Context, key string, expires time.Duration) (string, error)

    // 关闭连接
    Close() error
}
```

### 支持的实现

| 存储提供商 | 配置类型 | 文件 |
|----------|--------|------|
| 阿里云 OSS | `"oss"` | `oss_storage.go` |
| 火山云 TOS | `"tos"` | `tos_storage.go` |

## 使用方法

### 1. 初始化存储

#### 使用 OSS（现有方式，兼容）：

```go
import "cloud_disk/core/utils"

cfg := utils.StorageConfig{
    Type:            "oss",
    Region:          "cn-beijing",
    // OSS 会自动从环境变量加载：OSS_ACCESS_KEY_ID, OSS_ACCESS_KEY_SECRET, OSS_BUCKET_NAME
}

err := utils.InitStorage(cfg)
if err != nil {
    panic(err)
}
```

#### 使用 TOS（火山云）：

```go
import "cloud_disk/core/utils"

cfg := utils.StorageConfig{
    Type:            "tos",
    Region:          "cn-beijing",
    Endpoint:        "tos-cn-beijing.volces.com",
    BucketName:      "my-bucket",
    AccessKeyID:     os.Getenv("VOLCENGINE_ACCESS_KEY_ID"),
    AccessKeySecret: os.Getenv("VOLCENGINE_SECRET_ACCESS_KEY"),
}

err := utils.InitStorage(cfg)
if err != nil {
    panic(err)
}
```

### 2. 获取和使用存储实例

```go
import "cloud_disk/core/utils"

// 获取存储实例
storage, err := utils.GetStorage()
if err != nil {
    return err
}

// 上传文件
err = storage.PutObject(ctx, "path/to/file", fileReader, fileSize, "application/octet-stream")

// 生成下载链接
url, err := storage.GetPresignedURL(ctx, "path/to/file", 1*time.Hour)

// 删除文件
err = storage.DeleteObject(ctx, "path/to/file")
```

### 3. 分片上传示例

```go
import "cloud_disk/core/utils"

storage, _ := utils.GetStorage()

// 1. 初始化分片上传
uploadID, err := storage.InitiateMultipartUpload(ctx, "large-file.zip", "application/zip")

// 2. 并发上传分片
parts := []utils.Part{}
for i := 1; i <= numParts; i++ {
    etag, err := storage.UploadPart(ctx, "large-file.zip", uploadID, i, partReader, partSize)
    if err != nil {
        // 失败时取消上传
        storage.AbortMultipartUpload(ctx, "large-file.zip", uploadID)
        return err
    }
    parts = append(parts, utils.Part{PartNumber: i, ETag: etag})
}

// 3. 完成上传
err = storage.CompleteMultipartUpload(ctx, "large-file.zip", uploadID, parts)
```

## 迁移指南

### 从直接 OSS 调用迁移

**之前的方式：**
```go
// 直接调用 OSS 函数
key, err := utils.UploadToOSS(fileReader, originalFilename)
etag, err := utils.UploadToOSSMultipart(filePath, originalFilename, fileSize)
url, err := utils.PresignGetObject(ctx, objectKey, expires)
err := utils.DeleteOSSObject(ctx, objectKey)
```

**迁移后的方式：**
```go
// 使用统一接口
storage, err := utils.GetStorage()

// 上传
err = storage.PutObject(ctx, key, fileReader, fileSize, "application/octet-stream")

// 分片上传
uploadID, _ := storage.InitiateMultipartUpload(ctx, key, contentType)
etag, _ := storage.UploadPart(ctx, key, uploadID, partNumber, partReader, partSize)
// ... 上传所有分片后
err = storage.CompleteMultipartUpload(ctx, key, uploadID, parts)

// 生成链接
url, err = storage.GetPresignedURL(ctx, key, 1*time.Hour)

// 删除
err = storage.DeleteObject(ctx, key)
```

## 环境变量配置

### OSS 配置（自动从环境变量加载）

```bash
OSS_ACCESS_KEY_ID=your_access_key
OSS_ACCESS_KEY_SECRET=your_secret_key
OSS_REGION=cn-beijing
OSS_BUCKET_NAME=my-bucket
```

### TOS 配置

```bash
VOLCENGINE_ACCESS_KEY_ID=your_access_key
VOLCENGINE_SECRET_ACCESS_KEY=your_secret_key
VOLCENGINE_REGION=cn-beijing
VOLCENGINE_ENDPOINT=tos-cn-beijing.volces.com
VOLCENGINE_BUCKET_NAME=my-bucket
```

## 向后兼容性

现有的 OSS 直接调用函数（如 `UploadToOSS`、`PresignGetObject` 等）仍然可用，但建议逐步迁移到统一接口。
